# Servo Driver HAT（PCA9685）—— Quectel Pi M2

基于 NXP PCA9685 的 16 路 12 位 PWM 舵机驱动板，通过 40Pin 的
I2C-3（Pin3/5）或 I2C-7（Pin27/28）接到 Quectel Pi M2（RK3576）。
本目录包含控制脚本与使用说明。

## 1. 目录内容

| 文件 | 说明 |
|---|---|
| `M2_pca9685-servo.sh` | M2 控制脚本：交互菜单 + 同步扫动 + 寄存器回读校验 |
| `README.md` | 本文件：接线、用法与排错 |

> 原厂数据手册与例程不随仓库发布。

> 仓库总览见上一层 `README.md` 的「PCA9685 16 路舵机驱动板」一节。

## 2. 硬件连接

### 2.1 40Pin 接线（M2）

| PCA9685 模块 | M2 40Pin | 说明 |
|---|---|---|
| `VCC` | Pin1 / Pin17（3.3V） | PCA9685 逻辑电源，同时决定 I2C/PWM 电平 |
| `V+` | Pin2 / Pin4（5V）或独立 5–6V | 只给舵机排针的红色电源脚供电 |
| `GND` | Pin6 / Pin9 等 | 逻辑地与舵机电源必须共地 |
| `SDA` | Pin3（I2C-3）或 Pin27（I2C-7） | I2C 数据 |
| `SCL` | Pin5（I2C-3）或 Pin28（I2C-7） | I2C 时钟 |
| `OE` | GND | 低电平使能输出；悬空容易受干扰 |

两组 I2C 二选一即可。脚本不带 `-b` 时会扫描所有 `/dev/i2c-*`，用
`0x40` + ALLCALL `0x70` 两个地址确认 PCA9685，自动选中实际接线的那条；
其他板卡（例如 PCA9685 挂在 i2c-0 / i2c-1）也适用。也可以显式指定
`-b 0`、`-b 1`、`-b 3`、`-b 7` 等。

I2C 地址默认为 `0x40`；`i2cdetect -y -r 3`（或 `-r 7`）里同时出现的 `0x70`
是 PCA9685 的 ALLCALL 地址，不是第二颗芯片。

### 2.2 舵机接口

每个 3Pin 舵机座：

| 舵机线色 | 接到 |
|---|---|
| 棕 / 黑 | GND |
| 红 | V+（5–6V） |
| 黄 / 橙 / 白 | PWM 信号 |

### 2.3 供电注意（重要）

- **`V+` 必须接 5–6V**。接 3.3V 时舵机可能出现“有保持力、但扫动时不动”的现象，
  这是已经实测确认过的故障原因。
- **`VCC` 保持 3.3V**。多数模块的 `SDA/SCL` 上拉电阻接在 `VCC` 上，`VCC` 接 5V
  会把 M2 的 3.3V I2C 引脚拉到 5V，可能损坏 RK3576 IO。除非模块明确带电平转换。
- 三颗小舵机可用 M2 的 5V 引脚做快速验证；MG996R 这类大扭矩舵机或多路同时动作，
  建议用独立 5–6V 电源，电源负极与 M2 共地。
- 接线或换线前先断开开发板电源，避免带电插拔损坏外设或主板。

## 3. 快速使用

```bash
cd Servo-driver-HAT
sudo ./M2_pca9685-servo.sh
```

脚本会初始化 PCA9685（50 Hz、推挽输出），然后进入交互菜单：

```
===== PCA9685 servo control (i2c-3, addr 64) =====
  channels: 4 8 12 (board label = channel + 1)
  1) all selected channels -> angle
  2) one channel -> angle
  3) synchronized sweep
  4) turn all outputs off
  0) exit (keep last position)
Select:
```

| 选项 | 行为 |
|---|---|
| `1` | 输入角度 `0–180`，三路同时转到该角度 |
| `2` | 先输入通道 `0–15`，再输入角度，只动这一路 |
| `3` | 三路同步往返扫动，扫完停在中位 |
| `4` | 关闭全部 16 路输出，舵机卸力 |
| `0` | 退出，保持最后角度（不自动关输出） |

### 3.1 命令行参数

```bash
sudo ./M2_pca9685-servo.sh                 # 交互菜单，默认通道 4 8 12
sudo ./M2_pca9685-servo.sh -t              # 不进菜单，直接跑一轮同步扫动
sudo ./M2_pca9685-servo.sh -b 7            # 强制使用 Pin27/28 的 I2C-7
sudo ./M2_pca9685-servo.sh -c "0 1 2"      # 指定参与菜单/扫动的通道
sudo ./M2_pca9685-servo.sh -p "1000 2000"  # 修改 0–180° 对应的脉宽范围
sudo ./M2_pca9685-servo.sh -s 25           # 修改扫动步进（µs）
sudo ./M2_pca9685-servo.sh -b 3 -a 0x40    # 手动指定 I2C 总线/地址
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-b` | 自动扫描 | I2C 总线号；不指定时扫描所有 `/dev/i2c-*`，指定后不再自动探测 |
| `-a` | `0x40` | PCA9685 7 位地址 |
| `-c` | `"4 8 12"` | 默认通道；板载丝印 5/9/13 对应寄存器通道 4/8/12 |
| `-p` | `"500 2500"` | 0° 和 180° 对应的脉宽（µs） |
| `-s` | `50` | 扫动步进（µs） |
| `-t` | 无 | 跑一轮同步扫动后退出，输出停在中位 |
| `-h` | 无 | 帮助 |

> 脚本默认通道是 **0 基寄存器通道**。如果板子丝印本身是 0 基、舵机实际在
> 5/9/13 号座，请用 `-c "5 9 13"`。用 `-c "0 1 2 ... 15"` 可以逐路找舵机。

### 3.2 角度与脉宽

角度线性映射到 `PULSE_MIN`–`PULSE_MAX`：

```
pulse_us = PULSE_MIN + angle × (PULSE_MAX − PULSE_MIN) / 180
```

默认 `500–2500 µs`：

| 角度 | 脉宽 | 12 位计数值 |
|---|---|---|
| 0° | 500 µs | 102 |
| 45° | 1000 µs | 205 |
| 90° | 1500 µs | 307 |
| 180° | 2500 µs | 512 |

## 4. 脚本实现要点

初始化序列（均来自数据手册）：

1. `MODE1=0x10`：置 SLEEP，关闭振荡器，允许写 `PRE_SCALE`。
2. `MODE2=0x04`：`OUTDRV=1` 推挽输出，`INVRT=0` 输出不反相。
3. `PRE_SCALE=121 (0x79)`：`25 MHz / (4096 × 50) − 1 = 121`，得到 50 Hz。
4. `MODE1=0x21`：唤醒，等 10 ms（手册要求 ≥500 µs）。
5. 16 路全部写 full-OFF，再写 `MODE1=0xA1` 清 RESTART，避免续发旧脉宽。
6. 每通道写 `LEDn_ON_L/H + LEDn_OFF_L/H` 共 4 字节，使用 `i2cset ... i`
   I2C 块写，4 个寄存器在 STOP 时一起生效，避免逐字节写入造成中间脉宽抖动。
7. 输出 `ON=0`、`OFF=ticks`，`ticks = round(pulse_us × 4096 / 20000)`。

PASS 判定：每个通道在最大/最小脉宽处回读 `LEDn_OFF` 寄存器，与写入值一致；
舵机是否跟随需要肉眼确认。

## 5. 实测记录（M2 + 3 颗舵机）

- `i2cdetect -y -r 3` / `-y -r 7`：对应总线上 `0x40`、`0x70` 正常出现。
- 默认通道 4/8/12 同步扫动，三颗舵机全部动作。
- 当前接线在 Pin27/28（i2c-7）：不带 `-b` 时自动扫描所有 `/dev/i2c-*`，命中 i2c-7；
  同一脚本在 i2c-0 / i2c-1 等总线上同样适用。
- 菜单设 90°：通道 4/8/12 回读为 1500 µs（`OFF=0x0133`）。
- 菜单单路设通道 8 为 45°：回读为 1000 µs（`OFF=0x00CD`）。
- 菜单关闭输出：`LEDn_OFF_H=0x10`，full-OFF 生效。
- 早期故障：`V+` 接 3.3V 时三颗舵机只有保持力、扫动时不动；改接 5V 后恢复。

## 6. 常见问题

| 现象 | 排查 |
|---|---|
| `i2cdetect` 看不到 `0x40` | 检查 VCC 3.3V、GND、SDA/SCL；逐个扫 `for b in /dev/i2c-*; do i2cdetect -y -r ${b##*-}; done` |
| 能看到 `0x40` 但舵机不动 | 先量舵机座 `V+` 对 GND 是否 5–6V；检查 OE 是否低、舵机插头方向 |
| 有保持力但扫不动 | `V+` 电压不足，常见是接到了 3.3V |
| 只有某一路不动 | 通道号不对或该路舵机/排线问题；用 `-c "0 ... 15"` 逐路确认 |
| 报 `MODE1.EXTCLK is set` | 芯片被切到外部时钟，软件无法清除，断电重启后再试 |
| 舵机抖动/复位 | 电源电流不足，换独立 5–6V 电源并共地，必要时加滤波电容 |
